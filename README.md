# 🚀 Advanced Java Repository

### 📌 About

A collection of **Advanced Java** concepts, assignments, and mini projects built using **Java, Hibernate, MySQL, HTML, and JavaScript**. This repository demonstrates clean layered architecture, Hibernate ORM, Stream API, and CRUD-based web applications for hands-on learning and backend development. ([GitHub][1])

---

## ✨ Features

* 🚀 Advanced Java concepts and practical implementations
* 📚 Stream API assignments and practice programs
* 🗄️ Hibernate ORM integration with MySQL
* 🔗 Hibernate Mapping examples:

  * One-to-One
  * One-to-Many
  * Many-to-One
* 🎓 Student Management System (CRUD)

  * ➕ Add Student
  * 🔍 Search Student
  * 📋 Display All Students
  * ✏️ Update Student
  * ❌ Delete Student
  * 📊 Sort Students
* 🏗️ Layered Architecture

  * 📦 Model
  * 🎮 Controller
  * ⚙️ Service
  * 🗃️ Repository (DAO)
* 🌐 Frontend integration using HTML & JavaScript
* 🗂️ REST-style Servlet APIs with JSON
* 💾 MySQL database connectivity using Hibernate
* 🛠️ Exception handling and validation
* 📁 Well-structured Maven project
